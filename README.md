# Wine Joy Studio — static homepage study

Static, responsive reconstruction of the supplied 3840×2160 reference image.

Open `index.html` directly, or serve the directory locally:

```sh
python3 -m http.server 4173
```

The supplied reference is a static screenshot rather than an inspectable webpage. Accordingly, layout, type, color, and glow values are visual fits (`GUESS` in the web-shader-extractor evidence vocabulary); there is no source shader or runtime render graph to extract in this phase.
